Welcome to the **Parque de la Conservación** repository. This project is a modern web application dedicated to the wildlife conservation center in Medellín, Colombia.

## 📖 Project Overview

The **Parque de la Conservación** (formerly known as Santa Fe Zoo) is a vital space for the rescue, rehabilitation, and protection of wild species. This digital platform aims to bridge the gap between the park's conservation efforts and the community, providing an educational and interactive experience for visitors and nature enthusiasts.

### 🌟 Key Features
- **Educational Species Catalog**: Detailed information about the flora and fauna protected within the park.
- **Conservation Initiatives**: Insights into the park's rehabilitation programs and environmental impact.
- **Visitor Information**: Interactive guides, schedules, and ticket information.
- **Responsive Design**: A seamless experience across mobile, tablet, and desktop devices.

## 🚀 Tech Stack

- **Framework**: [React](https://reactjs.org/) (Version 18)
- **Build Tool**: [Vite](https://vitejs.dev/)
- **Language**: [TypeScript](https://www.typescriptlang.org/)
- **Styling**: Vanilla CSS / Custom Modern UI

## 🛠️ Getting Started

### Prerequisites
Make sure you have [Node.js](https://nodejs.org/) installed on your machine.

### Installation
1. **Clone the repository**
   ```bash
   git clone https://github.com/sebastianvasquezechavarria1234/react-parque-de-la-consevacion.git
   ```
2. **Navigate to the directory**
   ```bash
   cd react-parque-de-la-consevacion
   ```
3. **Install dependencies**
   ```bash
   npm install
   ```

### Development
To start the local development server:
```bash
npm run dev
```

### Build for Production
To generate a production-ready bundle:
```bash
npm run build
```

## 📂 Project Structure
